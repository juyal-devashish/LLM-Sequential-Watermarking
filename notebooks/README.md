# Analysis notebooks

These notebooks are historical exploratory analyses. Their embedded outputs are preserved and have not been recomputed. A setup cell resolves the checkout from either the repository root or the notebooks directory; inputs live under `results/` and new plots are exported to `results/figures/`.

Install the `analysis` dependency group. Required raw `exp-del`, `exp-ins`, and `exp-sub` results are not included. Before using the notebooks to produce exhibit data, fix the filename-based rate inference and aggregation/provenance issues described in `../docs/VALIDATION.md`. Output preserved in a notebook is not proof that the current scripts reproduce it.
