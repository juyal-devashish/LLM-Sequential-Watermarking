Sequential watermark detection

Testing by betting for language model watermarks. A project demo comparing detection power, false positives, and the computation needed to reach a decision.

01 / THE IDEA

Research question

A language model can use a secret key while sampling words. A detector with the same key asks whether the resulting text aligns with it more closely than chance would suggest.

Our project explores a sequential Monte Carlo test: instead of committing to a fixed number of random comparisons, it checks the evidence as comparisons accumulate and can stop early.

03 / THE METHOD

Methodology

Generation and detection work together. The sequential test changes how long the detector continues comparing.

01

Generate

A shared key guides sampling from the language model, leaving a statistical signal in its output.

02

Compare

The detector measures how well the candidate text aligns with the key and compares it with randomized alternatives.

03

Decide

A sequential procedure monitors the evidence and may stop early for a rejection or for futility.

↳

A result concerns a specific watermark and key. A failure to find evidence does not prove text was written by a person.

05 / ABOUT THE PROJECT

Project & contributors

Developed during the University of Michigan’s CSE 598 course in Winter 2025 by Devashish Juyal, Emilio Cantu-Cervini, Zicheng Jin, and Sri Likhita Adru.
