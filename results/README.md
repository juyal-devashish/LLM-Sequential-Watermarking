# Results

`figures/` contains the 10 original project PNGs, preserved byte-for-byte. These are historical evidence, not newly reproduced measurements.

Generated experiment files belong under ignored `raw/` or a named ignored experiment folder. The original notebooks expect `exp-del/`, `exp-ins/`, and `exp-sub/`; those raw datasets are absent from this checkout.

Future audited JSON/CSV exports for the website will live under tracked `exhibit/`, each with provenance and schema version. See `../docs/EVIDENCE.md` and `../docs/VALIDATION.md`. Do not infer precise chart values from image pixels or present simulations as experimental measurements.
